Privacy Policy — Social Imperial Poster

Effective October 14, 2026 · Application: "Social Imperial Poster" · Operator: Social Imperial · Contact: copwiretv@gmail.com

The "Social Imperial Poster" is a private publishing tool operated by Social Imperial, a media operator that runs its own network of TikTok channels (including Copwire TV, Market Moments, and ESTM Play Network). It connects to TikTok through TikTok's official Content Posting API and Login Kit solely so that the operator can publish the operator's own videos to TikTok accounts that the operator itself owns and operates. Each account is connected by its owner through TikTok's authorization flow. This policy describes exactly what data the application accesses and how it is handled.

1. Data the application accesses

With each account owner's authorization (OAuth scopes user.info.basic and video.publish), the application accesses only:

  • The basic profile information of each authorizing account: display name, username, and avatar — used only to confirm the correct account is connected before posting.
  • An OAuth access token and refresh token for each authorizing account, used to call the Content Posting API for that account.
  • The video files, titles, and captions that the operator supplies for upload. These are the operator's own finished videos.

The application does not access any other TikTok user's data. It does not read messages, contacts, followers, or browsing activity, and it does not collect data about viewers of the published videos through the API. The application is never offered to, and cannot be authorized by, accounts that the operator does not own.

2. How the data is used

Data is used for one purpose only: publishing the operator's own videos to the operator's own TikTok accounts, including checking each account's posting eligibility and the upload status of each video. Data is never used for advertising, profiling, analytics resale, or any purpose unrelated to publishing the operator's own content.

3. Storage and security

OAuth tokens are stored on the operator's own systems in access-restricted files, transmitted only over HTTPS to TikTok's official API endpoints, and never embedded in published content or public code. Video files are stored on the operator's production systems as part of the channels' normal workflow.

4. Sharing

No data accessed through TikTok's API is sold, rented, shared, or transferred to any third party. Data flows only between the operator's systems and TikTok's official API endpoints.

5. Retention and revocation

Tokens are retained only while the application remains in use for publishing to the relevant account. An account owner may revoke the application's access at any time in TikTok's settings (Settings and privacy → Manage apps and websites) or by contacting the operator at copwiretv@gmail.com, after which stored tokens for that account are deleted. Revocation takes effect immediately for future API calls.

6. Platform policies

The application's use of information received from TikTok APIs complies with the TikTok Developer Guidelines and TikTok's Privacy Policy. Use of TikTok is also governed by TikTok's Terms of Service.
