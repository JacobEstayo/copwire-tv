Privacy Policy — Copwire TV Poster

Effective October 14, 2026 · Application: "Copwire TV Poster" · Operator: Copwire TV · Contact: copwiretv@gmail.com

The "Copwire TV Poster" is a private publishing tool operated by Copwire TV. It connects to TikTok through TikTok's official Content Posting API and Login Kit solely so that Copwire TV's operator can publish Copwire TV's own videos to Copwire TV's own TikTok account (@copwiretv). This policy describes exactly what data the application accesses and how it is handled.

1. Data the application accesses

With the account owner's authorization (OAuth scopes user.info.basic and video.publish), the application accesses only:

  • The basic profile information of the authorizing account (the @copwiretv account itself): display name, username, and avatar — used only to confirm the correct account is connected before posting.
  • An OAuth access token and refresh token for that account, used to call the Content Posting API.
  • The video files, titles, and captions that the operator supplies for upload. These are Copwire TV's own finished videos.

The application does not access any other TikTok user's data. It does not read messages, contacts, followers, or browsing activity, and it does not collect data about viewers of the published videos through the API.

2. How the data is used

Data is used for one purpose only: publishing the operator's own videos to the operator's own TikTok account, including checking the account's posting eligibility and the upload status of each video. Data is never used for advertising, profiling, analytics resale, or any purpose unrelated to publishing the channel's own content.

3. Storage and security

OAuth tokens are stored on the operator's own systems in access-restricted files, transmitted only over HTTPS to TikTok's official API endpoints, and never embedded in published content or public code. Video files are stored on the operator's production systems as part of the channel's normal workflow.

4. Sharing

No data accessed through TikTok's API is sold, rented, shared, or transferred to any third party. Data flows only between the operator's systems and TikTok's official API endpoints.

5. Retention and revocation

Tokens are retained only while the application remains in use for publishing. The account owner may revoke the application's access at any time in TikTok's settings (Settings and privacy → Manage apps and websites) or by contacting the operator at copwiretv@gmail.com, after which stored tokens are deleted. Revocation takes effect immediately for future API calls.

6. Platform policies

The application's use of information received from TikTok APIs complies with the TikTok Developer Guidelines and TikTok's Privacy Policy. Use of TikTok is also governed by TikTok's Terms of Service.

7. Changes

Material changes to this policy will be posted at this URL with a revised effective date before they take effect.
